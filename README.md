# Helena LIS — update channel

Public, read-only update channel polled by Helena Desk on lab PCs.

- `latest.json` — manifest of the current delivery release (version, image tags, digests).
- `manifests/<tag>.json` — every published release.

No source code, credentials or lab data live here. Images are private on GHCR.
Written only by the `Delivery release` workflow of the (private) Helena LIS repo.
